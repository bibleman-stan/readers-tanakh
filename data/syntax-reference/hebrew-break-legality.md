# Hebrew Break Legality Reference

**Layer 1.** Universal Hebrew grammatical floor. Permission/prohibition surface only — does not prescribe choices among permitted alternatives. Editorial decisions live in `private/01-method/colometry-canon.md` (Layer 3). Three-layer architecture, migration discipline, and rule-to-table mapping are documented in canon §4.

**Shape cap.** The break-legality table below is table-only. No prose explanations, no examples, no exceptions in cells. **Row cap: 24** (current population: 22). Any addition requiring more than `signature | legality | reference` belongs in the canon, not here.

**Legality vocabulary** (column 2):

- `REQUIRED-MERGE` — break forbidden; units must stay on the same line
- `PERMITTED-EITHER` — both split and merge are grammatically legal; editorial judgment governs
- `REQUIRED-BREAK` — break mandatory (no Hebrew cases identified to date)
